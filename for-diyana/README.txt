WEBSITE ULANG TAHUN KE-29 — UNTUK SAYANG ♡

CARA MEMBUKA
1. Ekstrak folder `ultah-ldr-29` dari file ZIP.
2. Buka foldernya, lalu klik dua kali `index.html` untuk membukanya di browser.
3. Internet hanya diperlukan untuk memuat font Google. Website inti tetap bisa dibuka secara lokal.

CARA MEMASUKKAN FOTO DIA
Salin foto milikmu ke folder `assets`, lalu gunakan nama file persis berikut:
- foto-1.jpg
- foto-2.jpg
- foto-3.jpg
- foto-4.jpg
- foto-5.jpg
- foto-6.jpg

Kalau foto kamu formatnya PNG, ubah juga nama di `index.html` dari `.jpg` menjadi `.png` pada foto terkait. Hindari spasi pada nama file.

CARA MENGGANTI BACKSOUND
1. Pilih file musik MP3 yang ingin dipakai.
2. Masukkan ke folder `assets` dan beri nama `backsound.mp3`.
3. Buka website lalu tekan tombol “Putar lagu kita”.

Catatan: browser umumnya tidak mengizinkan audio otomatis berbunyi sebelum pengunjung menekan tombol. Karena itu, tombol putar musik disediakan agar musik bisa dimulai dengan satu sentuhan.

CARA MENGUBAH TEKS / SAPAAN
Buka `index.html` menggunakan editor teks atau Visual Studio Code. Gunakan Ctrl+F untuk mencari tulisan seperti:
- `Sayang`
- `Dari seseorang di Indonesia`
- `manusia kesayanganku`
- teks pada surat rahasia di bagian `letter-body`

Silakan ubah agar terasa lebih personal. Detail lokasi Depok–Terengganu ada di bagian jarak; jarak udara dihitung otomatis dari koordinat perkiraan pusat kota Depok dan Kuala Terengganu, jadi bukan jarak jalan atau rute penerbangan.

FILE
- index.html : struktur konten website
- style.css  : desain, warna, layout, animasi, dan tampilan mobile
- script.js  : musik, galeri foto, surat modal, animasi hati/kelopak, dan perhitungan jarak
- assets/    : tempat memasukkan enam foto dan file MP3

Dibuat responsif untuk desktop dan ponsel.
